# Diabetes Hospital Readmission Prediction

Exploratory analysis and preprocessing for predicting **30-day hospital readmission** in diabetic patients, using the [UCI Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/ml/datasets/Diabetes+130-US+hospitals+for+years+1999-2008+Data).

---

## Repository scope

This repository contains the **publicly shareable portion** of a larger machine learning project: exploratory data analysis, feature engineering, and preparation of modeling-ready datasets.

The following are **not included**:

- Model training and evaluation pipelines
- Neural network architectures and experiments
- Production or deployment-related code

Those components were developed in a professional context and remain subject to **intellectual property rights** of the organization where that work was carried out. They cannot be published in this repository.

What is shared here demonstrates data cleaning, feature construction, class-imbalance handling, and exploratory analysis on an open dataset.

---

## Problem

Hospital readmissions within 30 days are costly and often preventable. The analysis prepares a binary classification task using clinical, demographic, and medication features available at discharge.

| | |
|---|---|
| **Task** | Binary classification |
| **Positive class** | Readmitted within 30 days (`<30`) |
| **Negative class** | Not readmitted, or readmitted after 30 days (`NO`, `>30`) |
| **Challenge** | Severe class imbalance (~11% positive after preprocessing) |

---

## What's included

- Cleaning of **101k+ encounters** down to **96,446** usable rows
- Feature engineering with **980+ features** (diagnosis dummies, medication-change counts, interaction terms, service utilization)
- SMOTE oversampling and random undersampling for class imbalance
- Normalized train/test splits and subsampled training sets
- Exploratory visualizations comparing readmission groups

## Methodology

### Data cleaning
- Dropped high-missing columns: `weight`, `payer_code`, `medical_specialty`
- Removed invalid rows: unknown diagnoses/race, expired patients, unknown gender
- Dropped unused medication columns (`citoglipton`, `examide`)

### Feature engineering
- Collapsed admission/discharge category IDs into clinically similar groups
- One-hot encoded ICD diagnosis codes (`diag_1`, `diag_2`, `diag_3`)
- Created `numchange` (medication change count) and `service_utilization`
- Added pairwise interaction terms (e.g. `num_medications × time_in_hospital`)
- Mapped age brackets to numeric midpoints; binarized the target variable

### Dataset preparation
- Train/test split: 70/30 (`random_state=2020`)
- Imbalance handling: SMOTE oversampling and random undersampling
- Scaling: `StandardScaler` on numeric features
- Subsampling: 80%, 60%, 40%, and 20% fractions of the oversampled train set
